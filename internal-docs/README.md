# internal-docs

Internal engineering notes — **not shipped with the gem** (excluded from `spec.files`).

- `plans/` — superpowers implementation plans (`YYYY-MM-DD-<feature>.md`)
- `specs/` — superpowers design specs (`YYYY-MM-DD-<topic>-design.md`)

Also the home for any other internal design drafts.

User-facing documentation lives in `docs/` (the guides linked from the README, and
reserved for a future VitePress site). Keep internal drafts out of `docs/`.
